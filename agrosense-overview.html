Objetivo do projeto

Implementar um sistema que capture leituras de sensores de solo (umidade, temperatura, luminosidade) em vários talhões de uma fazenda simulada, processe essas leituras em tempo real e disponibilize o resultado — histórico e alertas — em três clientes diferentes: um painel web pro agrônomo, uma estação desktop pra sede da fazenda e um app mobile pro produtor rural no campo.

O mesmo backend e a mesma API atendem os três clientes, o que é justamente o ponto central da disciplina: um sistema, múltiplas plataformas de acesso.

O que a ementa exige

  • Sistemas distribuídos (concorrência, openness, escalabilidade)
  • Protocolo de mensageria (MQTT)
  • Broker de recepção de dados (Mosquitto)
  • Armazenamento em grande escala (MongoDB)
  • Mineração de dados em tempo real (data streaming)
  • Utilização de APIs (REST + WebSocket)
  • Desenvolvimento dirigido a testes (TDD)
  • Integração com dispositivos IoT
  • Controle de versionamento (Git)

Evento científico de referência — SBIAGRO
