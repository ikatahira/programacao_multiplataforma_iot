Contexto — Enviando Dados para o Template

A ponte entre a view e o HTML

❓ O que é contexto

Como a view fala com o template

O contexto é um dicionário Python que você passa como terceiro argumento do render(). As chaves do dicionário viram variáveis disponíveis no template com a sintaxe {{ chave }}.

⚙️ Exemplo completo

View → Contexto → Template

# galeria/views.py
from django.shortcuts import render
from galeria.models import Fotografia

def index(request):
    # 1. Buscar dados do banco
    fotografias = Fotografia.objects.filter(publicada=True)

    # 2. Montar o contexto
    contexto = {
        'fotografias': fotografias,
        'titulo': 'Space Gallery',
    }

    # 3. Renderizar passando o contexto
    return render(request, 'galeria/index.html', contexto)
<!-- templates/galeria/index.html -->
{% extends 'galeria/base.html' %}

{% block conteudo %}
  <h1>{{ titulo }}</h1>

  {% for fotografia in fotografias %}
    <div class="card">
      <h2>{{ fotografia.nome }}</h2>
      <p>{{ fotografia.descricao }}</p>
    </div>
  {% empty %}
    <p>Nenhuma foto publicada.</p>
  {% endfor %}
{% endblock %}
🔡 Sintaxe de variáveis

Acessando atributos no template

{# Variável simples #}
{{ titulo }}

{# Atributo de um objeto #}
{{ fotografia.nome }}
{{ fotografia.data_fotografia }}

{# Filtros de template #}
{{ fotografia.nome|upper }}           {# MAIÚSCULAS #}
{{ fotografia.descricao|truncatechars:100 }}  {# Limita caracteres #}
{{ fotografia.data_fotografia|date:"d/m/Y" }} {# Formata data #}

Queries ORM

Consultando o banco sem escrever SQL

📋 Principais métodos

O Manager objects

Todo model Django tem um gerenciador chamado objects que permite consultar o banco de dados com Python puro, sem SQL:

MétodoO que faz
Fotografia.objects.all()Retorna todas as fotos
Fotografia.objects.filter(...)Retorna fotos que atendem a condição
Fotografia.objects.exclude(...)Exclui fotos que atendem a condição
Fotografia.objects.get(pk=1)Retorna um único objeto pelo ID
Fotografia.objects.order_by(...)Ordena o resultado
Fotografia.objects.count()Conta quantos registros existem
Fotografia.objects.first()Retorna o primeiro registro
💻 Exemplos práticos

Queries mais usadas na galeria

from galeria.models import Fotografia

# Todas as fotos
Fotografia.objects.all()

# Só as publicadas
Fotografia.objects.filter(publicada=True)

# Ordenadas por data (mais recente primeiro)
Fotografia.objects.order_by('-data_fotografia')

# Publicadas e ordenadas — chaining
Fotografia.objects.filter(publicada=True).order_by('-data_fotografia')

# Total de fotos publicadas
Fotografia.objects.filter(publicada=True).count()
💡

O - antes do campo em order_by significa decrescente. Sem o -, a ordem é crescente.

🐚 Django Shell

Testando queries no terminal

Antes de usar na view, teste as queries no shell interativo do Django:

# Abrir o shell
python manage.py shell

# Dentro do shell:
>>> from galeria.models import Fotografia
>>> Fotografia.objects.all()
>>> Fotografia.objects.filter(publicada=True)
>>> exit()

Filtros Avançados

Field lookups — buscas precisas com ORM

🔍 Field lookups

Filtros com duplo underscore __

O ORM do Django usa campo__lookup para filtros mais sofisticados do que igualdade simples:

LookupEquivale a
nome__icontains='lua'WHERE nome ILIKE '%lua%'
nome__contains='Lua'WHERE nome LIKE '%Lua%' (case sensitive)
nome__startswith='N'WHERE nome LIKE 'N%'
data_fotografia__year=2024WHERE YEAR(data) = 2024
id__in=[1,2,3]WHERE id IN (1,2,3)
id__gte=5WHERE id >= 5
💻 Busca por nome

icontains — busca parcial sem case sensitivity

# galeria/views.py — view de busca
def buscar(request):
    termo = request.GET.get('buscar', '')

    if termo:
        fotografias = Fotografia.objects.filter(
            nome__icontains=termo,
            publicada=True
        )
    else:
        fotografias = Fotografia.objects.filter(publicada=True)

    return render(request, 'galeria/index.html', {
        'fotografias': fotografias,
        'termo': termo,
    })
🐍 get_object_or_404

Buscando um único objeto com segurança

Ao buscar por ID para a página de detalhe, use get_object_or_404 — ele retorna 404 automaticamente se o objeto não existir, em vez de lançar uma exceção feia:

from django.shortcuts import get_object_or_404

def imagem(request, foto_id):
    fotografia = get_object_or_404(Fotografia, pk=foto_id)
    return render(request, 'galeria/imagem.html', {
        'fotografia': fotografia
    })

Página de Detalhe

Exibindo uma foto individual com URL dinâmica

🗺️ URL com parâmetro

Rota dinâmica com <int:foto_id>

urlpatterns = [

    path('imagem/<int:foto_id>/', views.imagem, name='imagem'),
]
